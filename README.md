# Python_automation

Learning Python from basics — a collection of small scripts exploring core programming concepts alongside beginner-level security and networking automation.

## 📂 Contents

| File | Description |
|------|--------------|
| `3-attempt-lock.py` | A simple lockout simulation — restricts access after 3 failed password attempts. Demonstrates loops, conditionals, and basic input validation. |
| `brute-force.py` | A basic brute-force password guesser used to understand how brute-force attacks work at a conceptual level, for educational purposes only. |
| `firewall.py` | A minimal firewall simulation script — filters traffic/requests based on simple rule sets (e.g. IP or port blocking logic). |
| `port.py` | A basic port scanner used to check open ports on a target host, built to understand sockets and network scanning fundamentals. |

## 🎯 Purpose

This repository is part of a personal learning journey through Python, with a focus on scripts relevant to cybersecurity and networking concepts (locking mechanisms, brute-force logic, firewalls, and port scanning). It's intended for **educational purposes only**.

## ⚠️ Disclaimer

The scripts in this repository (especially `brute-force.py`, `firewall.py`, and `port.py`) are written strictly for **learning and educational purposes**. They are meant to be run only against systems you own or have explicit permission to test. Do not use these scripts on any network, host, or account without authorization.

## 🛠️ Requirements

- Python 3.x
- Standard library only (unless a specific script requires additional packages — check the top of each file for `import` statements)

## 🚀 Usage

Clone the repo and run any script directly:

```bash
git clone https://github.com/Pratham-16/Python_automation.git
cd Python_automation
python3 <script_name>.py
```
